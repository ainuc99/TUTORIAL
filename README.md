## 高级教程

> 高级教程属于云固件最难理解的内容，适合对云固件和计算机引导原理需要进一步提升的爱好者。

[300.概述](300/300.md)

高级教程整体描述和分章节说明，最后包括一个镜像引导的参考项目。

[301.启动原理](300/301.md)

镜像文件模拟成虚拟磁盘（虚拟硬盘或者虚拟光盘），通过加载虚拟磁盘中的引导程序，实现镜像文件启动。Windows PE ISO镜像，是遵循标准的镜像启动过程的典型范例。

[302.辅助启动](300/302.md)

镜像文件根据不同的操作系统，启动过程并不相同，有些操作系统需要修改对应的配置文件才能完成启动，但这种改动会使得后续镜像无法满足虚拟机启动。在这种情况下，使用辅助启动镜像来实现临时修改就是最佳选择。Windows系统的VHD/VHDx镜像，就是按照这种模式启动的典型镜像。

[303.操作系统镜像自主启动](300/303.md)

云固件主程序可以通过标准模式和辅助启动镜像模式来支持镜像文件启动，镜像文件内操作系统也改造自身来支持镜像文件内启动。

[304.镜像格式与扩展](300/304.md)

镜像文件都有自己的特定格式，常见的格式包括VHD、VHDx，还有VMDK、QCOW2等等格式。对于这些云固件非原生支持格式的Linux镜像，也可以通过辅助启动镜像实现启动。

[305.虚拟光盘](300/305.md)

虚拟光盘常见格式为ISO。除了Windows PE的ISO可以直接启动外，Linux LiveCD和Windows安装光盘ISO也可以通过辅助启动镜像来启动。

[306.链式引导](300/306.md)

UEFI固件支持链式引导，云固件可以通过引导其他引导程序，启动其他镜像格式。Windows PE的WIM格式，就可以通过这种方式实现启动。

[307.镜像启动范例](300/307.md)

本章提供了一个开源的UEFI项目，通过内存盘加载镜像文件，访问镜像文件内的ESP分区，识别/EFI/BOOT/BOOTX64.efi，并启动镜像。

[308.云固件工具与自定义界面](300/308.md)

云固件提供了vdboot.efi工具，可以结合rEFInd实现自定义启动界面。
